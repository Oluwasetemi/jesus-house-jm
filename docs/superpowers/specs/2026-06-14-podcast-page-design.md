# In The Pews — Podcast Page Design

**Date:** 2026-06-14  
**Route:** `/podcast`  
**Status:** Approved

---

## Overview

"In The Pews" is a youth-centered Christian roundtable podcast hosted by three young members of Jesus House Jamaica: **Amarachi**, **Ruth**, and **Joseph**. Each episode opens with a casual icebreaker segment, then moves into faith-focused hot-topic conversations (e.g., is church boring?, dress codes, anointing, church shopping). Episodes are ~28 minutes, released on the church's YouTube channel under the `/videos` (edited uploads) tab.

The `/podcast` page is a standalone route — not nested under Multimedia — discoverable via the main nav. Episodes must not appear in the sermon archive (`videos.json`).

---

## Data Layer

### `src/data/podcast.json` (auto-generated)

Generated by `scripts/fetch-youtube.py --podcast`. The script:

- Fetches the channel's `/videos` tab (not `/streams`)
- Filters for titles matching the regex `r"in\s+the\s+pews"` (case-insensitive)
- Extracts episode number via `r"episode\s+(\d+)"` → stored as `episodeNumber` (integer)
- Writes results to `src/data/podcast.json` (separate from `videos.json`)
- Default merge behaviour: newest first, deduplicated by video ID

Podcast episodes are **never written to** `src/data/videos.json` and do not appear in the sermon archive or watch-live page.

Example entry shape:
```json
{
  "id": "VnqO4Jj-NZY",
  "episodeNumber": 1,
  "title": "In the pews Episode 1",
  "date": "2026-06-11",
  "dateNice": "June 11, 2026",
  "duration": "28:25",
  "thumbnail": "https://img.youtube.com/vi/VnqO4Jj-NZY/mqdefault.jpg",
  "url": "https://www.youtube.com/watch?v=VnqO4Jj-NZY"
}
```

### `src/content/podcast/` (optional, per-episode show notes)

One Markdown file per episode, e.g., `episode-1.md`. Frontmatter:

```yaml
---
videoId: VnqO4Jj-NZY
episodeNumber: 1
topics:
  - Is church boring?
  - Church shopping
  - Dress codes
  - Anointing and accountability
---
```

Body: free-form Markdown show notes / summary. If no file exists for an episode, the show notes section does not render — the page degrades gracefully.

The `podcast` content collection is added to `src/content.config.ts` with this schema.

## Page Structure (`src/pages/podcast.astro`)

### 1. Hero

- Show title: **In The Pews**
- Tagline pulled from Episode 1 intro: *"A youth-centered Christian podcast — conversations in the church, outside the church."*
- Host names: Amarachi · Ruth · Joseph
- Brown/gold palette consistent with the site rebrand; lighter, more energetic feel than the standard service pages

### 2. Featured Episode (latest)

- YouTube `<iframe>` embed for the most recent episode
- Episode number badge, title, date, duration
- Show notes section below the embed (renders only if a matching `src/content/podcast/episode-N.md` exists)
- Topics list (from frontmatter `topics` array) rendered as pill tags

### 3. Episode Archive

- Grid of episode cards (thumbnail image, "Ep N" badge, title, date, duration)
- "Watch on YouTube" link per card (opens in new tab)
- "Show Notes" toggle/section per card — visible only when a content file exists for that episode
- Most-recent first order

## Fetch Command

```bash

# Incremental update (safe merge, keeps existing notes intact)
python3 scripts/fetch-youtube.py --podcast --merge
```
